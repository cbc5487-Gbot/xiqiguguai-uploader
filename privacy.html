曦奇古怪隱私說明

更新日期：2026-09-23。本工具供使用者將自行選取的影片傳送至自己的電腦與 YouTube 頻道。

處理的資料與用途

App 與工作站處理你選取的影片、檔名、拍攝時間、縮圖、內容雜湊、標題、上傳進度及相關 Google 檔案與影片識別碼。這些資料用於傳片、辨識重複內容、原片備份及显示操作紀錄。工作站可在本機辨識影片畫面的文字，提供上傳標題。

Google 授權及資料流向

Google 授權用於操作本 App 建立或經你授權存取的 Drive 檔案、辨識已授權 YouTube 頻道、讀取影片狀態及上傳影片。若你另外授予 YouTube 管理權限，工作站可依你逐支確認的操作刪除對應影片。Drive 用作中轉；工作站確認永久備份及 YouTube 上傳成功後可清理中轉暫存。

影片會傳送到你授權的 Google Drive 和 YouTube，並保存於你的電腦。App 本身不提供第三方共用影片伺服器。自動更新檢查會向 GitHub 請求版本資訊及安裝檔，GitHub 可收到一般網路連線資訊。

儲存與控制

授權資料、配對資訊、影片紀錄及本機備份保存在使用者的裝置。你可以在 Google 帳戶設定撤銷 App 存取權，在 Google Drive 或 YouTube 管理線上內容，並自行管理手機與電腦上的備份。撤銷授權不會自動刪除既有備份或已上傳影片。移除輸入資料夾的檔案不等於確認永久刪除線上影片。

使用限制

本 App 對 Google API 所取得資訊的使用與轉移遵守 Google API Services User Data Policy，包括 Limited Use 要求。Google 資料不出售、不用於廣告或訓練通用人工智慧模型。相關第三方服務另適用 Google 與 GitHub 自身政策。
